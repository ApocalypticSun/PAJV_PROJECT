# Project PAJV - Multiplayer Shooter Prototype

## 📖 Overview
**Project PAJV** is a multiplayer shooter game prototype developed using **Unity 6**. The project features a custom launcher with secure authentication, cloud-based backend integration, and a dedicated server architecture for real-time multiplayer interactions.

This project was developed in accordance with the [Project Requirements](https://ocw.cs.pub.ro/courses/pjv/laboratoare/2024/proiect) for the [PJV course](https://ocw.cs.pub.ro/courses/pjv).

## 🛠 Tech Stack & Tools

* **Engine:** Unity `6000.3.4f1`
* **Networking:** [DarkRift 2](https://assetstore.unity.com/packages/tools/network/darkrift-networking-2-95309) (Server-Side Networking)
* **Backend & Auth:** [PlayFab](https://playfab.com/)
* **Language:** C#

## ✨ Key Features

* **Custom Launcher:** Standalone launcher application that handles user login before starting the game instance.
* **Authentication System:** Secure login and registration integrated with **PlayFab**.
* **Multiplayer Architecture:** Real-time synchronization using **DarkRift** networking solution.
* **Gameplay:** Third-person shooter mechanics (prototype stage).
